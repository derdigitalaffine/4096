INSTALL // PLAY OFFLINE

Als App installieren

Die Tromu Spielewelt ist eine offlinefähige PWA. Nach dem ersten vollständigen Laden kannst du sie vom Home-Bildschirm starten und die gecachten Spiele auch ohne Verbindung öffnen.

ANDROID

Chrome

  1. Diese Seite in Chrome öffnen.
  2. Menü ⋮ öffnen.
  3. „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen.
  4. Installation bestätigen.
iOS / iPadOS

Safari

  1. Diese Seite in Safari öffnen.
  2. Auf Teilen tippen.
  3. „Zum Home-Bildschirm“ wählen.
  4. Mit „Hinzufügen“ bestätigen.
